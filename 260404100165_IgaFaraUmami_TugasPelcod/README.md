Program tersebut digunakan untuk menghitung nilai akhir peserta dan menentukan status kelulusan berdasarkan nilai tugas, kuis, ujian, serta persentase kehadiran. 

Pertama masukkan nama peserta, nilai tugas, nilai kuis, nilai ujian, dan persentase kehadiran. Setelah itu, program menghitung nilai akhir dengan bobot tugas sebesar 30%, kuis 20%, dan ujian 50%.

Selanjutnya program menggunakan percabangan if, elif, dan else untuk menentukan status kelulusan. Jika kehadiran kurang dari 75%, peserta dinyatakan tidak lulus. Jika nilai akhir minimal 85 dan kehadiran minimal 80%, peserta mendapatkan predikat A. Jika nilai akhir minimal 75 dan kehadiran minimal 80%, peserta mendapatkan predikat B. Jika nilai akhir minimal 65 dan kehadiran minimal 75%, peserta mendapatkan predikat C. Jika tidak memenuhi salah satu dari ketentuan tersebut, peserta dinyatakan tidak lulus.

Terakhir, program menampilkan hasil akhir yang berisi nama peserta, nilai akhir, persentase kehadiran, dan status kelulusan.
