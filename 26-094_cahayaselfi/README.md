Program sederhana untuk menentukan kelulusan peserta pelatihan coding berdasarkan nilai dan kehadiran.

### Dibuat oleh: Cahaya Beautiful
### Bahasa:Python

### 1. Deskripsi Program
Program ini menerima input data peserta berupa nama, nilai tugas, nilai kuis, nilai ujian,dan persentase kehadiran. Kemudian program menghitung nilai akhir dan menentukan status kelulusan secara otomatis.

### 2. Ketentuan Penilaian
Nilai akhir dihitung dengan bobot:
- Tugas: 30% (0.3)
- Kuis: 20% (0.2)
- Ujian: 50% (0.5)
